# اختبارات قِسمة

تشتغل على نسخة من `qisma.html` في متصفح Chromium بدون واجهة، **ببيانات تجريبية فقط** — ما تتصل بالإنترنت ولا تلمس بياناتك الحقيقية ولا Firebase.

```bash
pip install playwright && playwright install chromium   # مرة وحدة
./tests/run_all.sh
```

| الملف | يفحص |
|---|---|
| `test_core.py` | كل الشاشات تفتح، معادلة القسمة (المالك + أنا + الشركاء + التكاليف = الدخل)، الحالة الافتراضية لـAirbnb، الحفظ ورسائل الرفض، تنبيه «متأخر» |
| `test_status_and_closed_month.py` | حفظ سحبة PayPal يغيّر **الحالة فقط** وكل حقل ثاني يبقى نفسه، والأرقام كلها ما تتغيّر؛ الشهر المقفل ما يضيّع المكتوب ولا يحفظ شي |
| `test_airbnb_paste.py` | لصق إيميل Airbnb يعبّي النموذج بدون حفظ، ورقم الحجز ظاهر لـAirbnb/Booking |
| `fuzz.py` | بيانات عشوائية كبيرة + ضغط كل الأزرار الآمنة، ويدوّر على NaN/undefined/أخطاء |

الإيميلات في `fixtures/` بأسماء وأرقام وهمية.
